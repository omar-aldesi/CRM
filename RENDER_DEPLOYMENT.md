# Render Deployment

This project is configured to run on Render with PostgreSQL.

## Required environment variables

Set these in the Render web service after the client creates the PostgreSQL database:

- `DATABASE_URL`: Render PostgreSQL internal URL, for example `postgresql://USER:PASSWORD@HOST:5432/DATABASE`
- `SECRET_KEY`: generated by Render through `render.yaml`

The settings also support split database coordinates if you do not use `DATABASE_URL`:

- `POSTGRES_DB` or `DB_NAME`
- `POSTGRES_USER` or `DB_USER`
- `POSTGRES_PASSWORD` or `DB_PASSWORD`
- `POSTGRES_HOST` or `DB_HOST`
- `POSTGRES_PORT` or `DB_PORT`

For custom domains, also set:

- `ALLOWED_HOSTS`: comma-separated hostnames, for example `example.com,www.example.com`
- `CSRF_TRUSTED_ORIGINS`: comma-separated origins, for example `https://example.com,https://www.example.com`

## Manual Render settings

If you do not use the included `render.yaml`, configure the web service manually:

- Runtime: Python 3
- Build command: `bash build.sh`
- Start command: `python -m gunicorn crm.asgi:application -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:$PORT`

The build script installs dependencies, collects static files, and runs migrations.
